Command Map

F = Forward · B = Backward · L = Left · R = Right · S = Stop
Q = Forward-left · E = Forward-right
Z = Back-left · C = Back-right
P/p = Spray ON/OFF · N/n = Seed ON/OFF
W/w = Front lights · U/u = Rear lights · V/v = Horn

IMPORTANT: Your Arduino program must use the same command map. The original G/g seed commands were changed to N/n because G conflicts with forward-left in the original mapping.
